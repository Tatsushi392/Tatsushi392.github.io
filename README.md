# Support site for Tatsushi392's iPhone apps

Published with GitHub Pages at https://tatsushi392.github.io/

- `index.html`: list of apps
- `style.css`: shared style (light and dark)
- one folder per app, each with `index.html` (support) and `privacy.html` (privacy policy). These URLs go into App Store Connect.

Add an app: copy `dateprintcamera/`, rename it, change the text and icon, and add a block to `index.html`.
